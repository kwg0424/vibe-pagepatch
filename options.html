      검색 이동

      주소창에 키워드만 치고 Enter 하면 검색하지 않고 지정한 주소로 바로 갑니다. 띄어쓰기는 상관없고(구글 지도 = 구글지도), 한/영 전환 없이 쳐도 됩니다(지도 = wleh = WLEH). 기본 검색엔진이 Google · Bing · 네이버 · 다음 · DuckDuckGo 일 때 동작합니다.

      주소 키워드

      등록된 키워드가 없습니다.

      키워드는 띄어쓰기를 빼고 저장합니다 (구글 지도 → 구글지도). 행을 누르면 위 입력란에 채워져 고칠 수 있고, 다른 주소에 있던 키워드를 넣으면 이 주소로 옮겨집니다. 목록은 규칙과 같이 동기화됩니다.

      키워드가 전에 가 본 주소로 자동완성되면 Edge 가 그 주소로 가 버립니다 → 자동완성 부분을 Delete 로 지우거나, 목록에서 Shift+Delete 로 지운 뒤 Enter.
